# Priyanka S Portfolio Website

A standalone personal portfolio website for Priyanka S, focused on AI/ML, DevOps, AWS Cloud, and production data pipelines.

## Open locally

Open [index.html](index.html) directly in a browser. No build step or dependencies are required.

## Files

- [index.html](index.html) - portfolio content
- [styles.css](styles.css) - responsive visual design
- [script.js](script.js) - scroll-reveal interaction
- `AWS Certified Solutions Architect - Associate certificate.pdf` - certification document linked from the website

## Publish

Upload these three files to GitHub Pages, Netlify, Vercel, or an S3 static website bucket. Keep employer-specific source code, account IDs, bucket names, credentials, and private links out of the public site.
